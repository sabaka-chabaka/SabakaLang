# SabakaLang

## Overview
SabakaLang is a statically typed, bytecode-compiled programming language designed for simplicity and productivity.
It focuses on ease of learning, while being easy to embed and extend from C#: you can add your own functions,
classes and even methods of built-in types (`"abc".shout()`) with a few attributes.

## Features
- **Simplicity:** Easy to read and write, C-like syntax.
- **Static typing with inference:** `var`, nullable types (`string?`), generics (`Box<int>`), interfaces, structs, enums.
- **Performance:** Compiled to bytecode and run on a stack VM with frame-local variables.
- **Extensible:** Write native modules in C# - functions, classes, extension methods, constants, enums.
- **Modules:** `import` other `.sabaka` files or native modules.
- **Cross-platform Compatibility:** Runs anywhere .NET runs (Windows, Linux, macOS).

## Quick look
```
import "geometry";                       // native module written in C#

interface IShape { float area(); }

class Circle : IShape {
    float r;
    Circle(float radius) { r = radius; }
    float area() { return PI * r * r; }  // PI comes from the built-in math module
}

IShape s = new Circle(2);
print($"area = {s.area()}");

int[] nums = [1, 2, 3];
nums.push(4);                            // methods on built-in types
foreach (int n in nums) {
    if (n == 2) { continue; }
    print(n);
}
```

## Getting started

### Requirements
.NET 11 SDK (the default target). If you only have .NET 10, add `-p:SabakaTfm=net10.0` to build commands.

### Build and run
```
dotnet build -c Release
dotnet run --project src/SabakaLang.Cli -- run script.sabaka
```

### CLI
```
sabaka run     <file.sabaka> [--ext <dll>]... [--ext-dir <folder>]   compile and run
sabaka check   <file.sabaka>                                         compile only, print diagnostics
sabaka dump    <file.sabaka>                                         print generated bytecode
sabaka modules [--ext <dll>]...                                      list native modules and their members
```
`--ext` can be repeated to load several libraries.

### Install as a global tool
Add to `src/SabakaLang.Cli/SabakaLang.Cli.csproj`:
```xml
<PackAsTool>true</PackAsTool>
<ToolCommandName>sabaka</ToolCommandName>
<PackageId>SabakaLang.Cli</PackageId>
```
then:
```
dotnet pack src/SabakaLang.Cli -c Release -o nupkg
dotnet tool install -g SabakaLang.Cli --add-source nupkg
```
Alternatively add `src/SabakaLang.Cli/bin/Release` to your `PATH`; every `dotnet build -c Release` then updates `sabaka`.

## Standard library
Auto-imported modules: `core` (`print`, `input`, `exit`, `ord`, `chr`, `parseInt`, `time`, ...),
`math` (`sqrt`, `pow`, `abs`, `min`, `max`, `floor`, `round`, `rand`, `PI`, ...), `io` (file access), `http`,
plus methods of strings (`upper`, `split`, `contains`, `substring`, ...) and arrays (`push`, `pop`, `slice`, `join`, ...).
Run `sabaka modules` for the full list.

## Writing extensions in C#
An extension is a normal class library that references `SabakaLang.Runtime`:

```csharp
[SabakaModule("geometry")]
public static class Geometry
{
    [SabakaClass("Vec2")]
    public sealed class Vec2
    {
        public Vec2(double x, double y) { X = x; Y = y; }
        [SabakaProperty] public double X { get; set; }
        [SabakaMethod]   public Vec2 Add(Vec2 o) => new(X + o.X, Y + o.Y);
    }

    [SabakaFunction] public static double Dot(Vec2 a, Vec2 b) => a.X * b.X;
    [SabakaExtension("string")] public static string Shout(string self) => self.ToUpper() + "!";
}
```
```
sabaka run script.sabaka --ext Geometry.dll
```

## Project layout
| Project | Purpose |
|---|---|
| `SabakaLang.AST`, `Lexer`, `Parser` | Front end |
| `SabakaLang.Binder` | Semantic analysis: names, types, overloads, generics, access control |
| `SabakaLang.Compiler` | Bytecode generation |
| `SabakaLang.VM` | Stack virtual machine and garbage collector |
| `SabakaLang.Runtime` | Values and the extension API |
| `SabakaLang.StdLib` | Standard library, built with the same extension API |
| `SabakaLang.Engine` | Embedding facade: compile, load imports, run |
| `SabakaLang.Cli` | The `sabaka` command |
